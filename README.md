A tiny program that writes one autocorrect fail to a text file. The line
is a single sentence of 53 characters: a text home from practice where
one wrong word turns a pulled muscle into a small pet.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
